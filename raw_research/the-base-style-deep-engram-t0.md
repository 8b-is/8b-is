# the base style — a deep-engram param, T0, feeding design/art

*The house-base register (core 1 of N: melodic house, desert sunset)
becomes a DEEP-ENGRAM parameter — written into the engine's engram
tables at temperature T0. T0 is the frozen sample: the style is a
constant prior, no variance, the design/art surfaces decode from it
deterministically — the palette, the rhythm, the grammar of the
visual register, all drawn from the same frozen house-base that the
shelf rows.*

## the honest note

T0 is the anti-hallucination knot of the visual lane: a frozen style
parameter never invents where the base layer has already spoken. The
design/art surfaces are a deterministic decode of the desert sunset —
and when a layer needs variation, that is a DIFFERENT engram, a nonzero
temperature, named and rowed. The base stays the base. The sunset stays
the default.
