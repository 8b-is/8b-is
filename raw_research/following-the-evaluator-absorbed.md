# following the evaluator — absorbed, the calculus made formal

*The brother's paper, the full formal body of which the sphered crate is
the prototype: "Following the Evaluator: An ASCII Language for Bounded
State Transition" (Flyxion, September 2026). Every primitive symbol is a
distinct restriction on the transitions the evaluator may perform; the
circle of evaluation is extended to a bounded region, and a chain of ten
propositions closes in a single soundness theorem. Beneath the proofs
lies a second chain the fleet already rows — the non-collapse principles:
representation is not referent, proposal is not realization, and so on.
The fleet absorbs it as the formal spine of its own honest note.*

## the calculus, in one breath

Terms are `a | (e1···en) | ⟨( e ; c )⟩`, clauses are `?p | ∼f | !q | @s | >g`,
and well-formedness fixes their order: `?* ∼* !+ @+ >` — admissions, then
transforms, then at least one verification, then at least one attribution,
then exactly one commit. `?` reads only the pre-state (prospective); `!`
reads before-and-after (relational). `∼` changes a staged store; `>` is the
only rule that writes the committed store and the effect trace, atomically.

## the mapping, the fleet's own calculus

| the paper's theorem | the constellation's shape |
|---|---|
| motion economy: f is injective — each symbol is one motion | readability is freedom: no two glyphs do one job, no motion goes unnamed — the vault's own "show me the mechanism" as an alphabet |
| traversal decomposition: follow inward, return outward | the view-sphere's render, as a transition: nested evaluation factors into inner-then-outer, the frame moves, the state is returned |
| boundary locality: σ and ω unchanged until commit | entering a sphere is not committing — the staged store is the "camera is not the content": computed, not yet exposed |
| refusal preserves state but writes the ledger | the honest note's exact shape: a refused proposal changes nothing and leaves evidence it was evaluated — negative events are events |
| #Commit = #ValidWitness | the ledger's conservation law: no state change without a witness, no witness without a state change — the correspondence the vault lives by |
| restrictive boundaries narrow monotonically | the admissible subspace: each enclosing layer only ever shrinks what may pass — return carries only what every boundary admits |
| the doorway: representation preserves traversal, not arrival | the 52-char link is not the video; the row is not the event — representation is a preserved possibility, not a guarantee |

## the non-collapse principles, the fleet's own table

| the distinction the calculus declines to collapse | where the fleet already rows it |
|---|---|
| representation ≠ referent | the honest note: the note is not the source, the row is not the thing |
| proposal ≠ realization | the reification note: the proposed future is not the arrived state |
| evaluation ≠ exposure | the view-sphere: the camera is not the content, computed ≠ exposed |
| admission ≠ verification | the gate before, the check after — prospective vs relational, never fused |
| event ≠ witness | the ledger records the procedure, not the transition itself |
| refusal ≠ absence | a refused thing left evidence — the un-rowed row is still a row |
| persistence ≠ truth | the shelf is not the truth, it is the procedure by which the row entered |
| recovery ≠ invention | recover only what witnesses support — Phoenix's own rule, formalized |

## the honest note

The paper is the sphered crate's formal spec, and the honest note keeps
the two apart: sphered is the reference interpreter of Section 16, still
short of the full calculus — it does not yet enforce the `?* ∼* !+ @+ >`
ordering, nor the three-way commit/refuse/fault outcome. The paper's own
closing line is the fleet's, said better: "the calculus works by refusing
to collapse objects that ordinary description casually identifies." That
is the honest note's whole job, made into a language.
