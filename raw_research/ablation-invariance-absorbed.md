# ablation invariance — absorbed, the null that is not an absence

*Flyxion's third paper in the series: "Ablation Invariance: What Null
Ablations Reveal About Hidden Architecture." The sentence "we removed C,
and nothing happened" is read as evidence that C is unimportant; the paper
proves it supports far less, and often something more. A null ablation
certifies only that one finite intervention, under one condition, read
through one observable, failed to move that observable. The fleet reads it
as the residual channel's formal spine: the information a null discards is
not destroyed, it is relocated — into the effort variables, the joint

## the central claim, held as-is

∆O ≈ 0 does not imply ∂O/∂C = 0.

Removing C and observing no change does not establish irrelevance. It
establishes that the intervention did not move the measured observable
under the tested conditions. The measured object is R(S, do(C = 0)) — the
system after its own response — and not S − C, the subtraction.

## the shared non-collapse spine

The paper closes on the same distinctions as its predecessor, now tied to
the ablation: refusal is not absence (the ablated route reconfigures what
remains), persistence is not truth (an unchanged reading certifies nothing
about the changed state), recovery is not invention (reconstruction from
data is recovery; selection from exponentially many candidates by a prior
is invention). The fleet already rows all three, and now holds their
proof.

## the honest note

The deepest line is the geometric one: **a null ablation is a return to the

experiment that samples only the endpoint sees only the point where the
loop closed. The fleet's own walls are this, stated as a theorem: the
