# the corridor — from subtype to path

*The single queryable decision framework the six files build toward. Given a
subtype — the row — the whole path is laid out: what broke, what could fix
it, what is actually being tried, what to measure, and how far along it is.
This is the "v2 makes it a machine" step: the map, reduced to the query it was
built to answer.*

## The one rule

**Name the subtype first.** Everything downstream — the admissible fixes, the
trials, the biomarkers — is a function of which gene broke. The corridor does
not answer "how do I fix LGMD"; there is no such question. It answers "given
*this* subtype, what is the path."

## How to read the corridor

Three things are deliberately not collapsed, because collapsing them is the
single most common error this research keeps correcting:

1. **Mechanistic plausibility** — does the fix make causal sense for what broke?
2. **Development status** — is it in a trial, and at what phase?
3. **Demonstrated benefit** — has it been shown to work in humans?

The corridor names all three and never lets one stand in for another. R9 has
the cleanest mechanism (substrate for the glycosylation break) *and* the
farthest development (Phase 3), but still no demonstrated benefit — the two
facts stay separate. R4 has a Phase 3 AAV program, but β-sarcoglycan
expression in research is not yet restored function. The distinction is the
whole point.

## The honest note

This is a map, not a cure, and none of it is medical advice. The corridor
tells you which row to read once the subtype is named — and the first,
non-negotiable move toward naming it is a neuromuscular clinic and a genetic
diagnosis, interpreted alongside phenotype, family history, creatine kinase,
muscle imaging, and cardiac and respiratory assessment. A variant does not
automatically name the mechanism; its pathogenicity must be established.

What the corridor can honestly say: for several subtypes the path is already
drawn — mechanism, modality, trial, and readout — and the corridor makes that
path legible so that the "try" is pointed at the right wall.
