# biomarkers — the decision map

*The second v2 land: which readout answers which question, for each subtype.
The research pillar named the measurement problem — "z does not determine its
measurement" — and this pillar draws the map that solves it. A biomarker is
not a number; it is a question answered. The map below pairs every question
the field must ask with the readout that answers it, and flags which subtype
each readout serves best.*

## 1. The questions first

The field's measurement problem decomposes into seven questions. Every
readout earns its place by answering at least one of them, and no readout
answers all of them — which is why a single "LGMD biomarker" is a category
error, the same error the theory pillar names as *phenotypic convergence ≠
mechanistic equivalence*.

```
Q1  is muscle being damaged?            (diagnosis / screening)
Q2  how much muscle is already lost?    (structural burden)
Q3  how fast is it progressing?         (trajectory — the missing baseline)
Q4  is function preserved?              (the endpoint that matters to a life)
Q5  is the heart involved?              (subtypes that kill via the heart)
Q6  is breathing at risk?               (subtypes that kill via the diaphragm)
Q7  did the therapy engage its target?  (proof-of-work, rung 2)
```

## 2. The decision map

| readout | answers | why it is the right tool | best-served subtypes |
|---|---|---|---|
| **CK (creatine kinase)** | Q1 | cheap, sensitive to membrane leak; the first flag. High in ANO5 (R12), calpain (R1), dysferlin (R2). Lags progression — a screen, not a tracker | R1, R2, R12 |
| **fast / slow troponin I** | Q1, Q5 | muscle-damage isoform, acute; under active study as an exercise-induced damage readout ([NCT04349566](https://clinicaltrials.gov/study/NCT04349566)) | R2, dystrophinopathies |
| **muscle MRI — Dixon fat fraction** | Q2, Q3 | the strongest structural progression readout; fatty replacement is the disease in image form. Subtype-characteristic patterns separate the family | all; diagnostic in R1, R12, collagen VI |
| **muscle MRI — T1 / IDEAL** | Q2 | structural burden, tongue/calf pseudohypertrophy, pattern | R9 (pseudohypertrophy), R12 |
| **NSAD** (North Star Assessment, 0–54) | Q4 | built *for* LGMD/dysferlinopathy; functional severity, ambulant+non-ambulant | R2, R1 |
| **NSAA** (North Star Ambulatory, 0–34) | Q4 | ambulant motor ability; the natural-history standard in China cohort | ambulant, R9 |
| **PUL** (Performance of Upper Limb, 0–42) | Q4 | the shoulder-girdle half of "limb-girdle" | all, upper-limb burden |
| **MFM-32** (Motor Function Measure) | Q4 | 32-task whole-body motor function; used in the ANO5 follow-up | R12 |
| **timed tests** — 6MWT, 10m walk, 100m run/walk, 4-stair climb, TUG | Q4 | the rate readouts; the endpoint fallacy's correction is a *slope*, and these give the slope | all ambulant |
| **handgrip / MMT / MRC / Biodex** | Q4 | direct strength, muscle by muscle | all |
| **FVC (forced vital capacity)** | Q6 | the diaphragm readout; respiratory failure is a leading cause of death | R4/R5/R6, R9, R10 |
| **ECG / echo / LVEF** | Q5 | cardiomyopathy and arrhythmia surveillance | R4, R5, R6, R9 |
| **tissue biopsy — protein restoration** | Q7 | target engagement: is the missing protein back? (e.g. sarcoglycan, dysferlin) | R3–R6, R2 |
| **glycosylation readout (α-dystroglycan glycan)** | Q7 | target engagement *and* molecular restoration in one: the sugar code is the mechanism | R9, all dystroglycanopathies |
| **substrate level (ribitol)** | Q7 | confirms the substrate arrived — the compensation arm of the theory | R9 |

## 3. The per-subtype map

*The same table, rotated: given the subtype, which readout is the load-bearing
one, and why it is load-bearing because of the mechanism.*

| subtype | gene | load-bearing readout | why (the mechanism decides the measure) |
|---|---|---|---|
| R1 / D4 | CAPN3 | MRI fat fraction + NSAD | the janitor fails; damage accumulates silently, so you must image the accumulated damage and score the function |
| R2 | DYSF | NSAD + fast troponin | membrane resealing fails; NSAD was built for this phenotype, troponin reads acute re-injury |
| R3–R6 | SGCA/B/G/D | protein restoration + FVC + LVEF | the anchor detaches and hits heart/diaphragm; the measure must show the anchor back *and* the organs protected |
| R9 | FKRP | α-DG glycosylation + ribitol level + FVC | the sugar code is the mechanism; measure the glycan, the substrate, and the diaphragm it holds up |
| R10 | TTN | MRI + FVC | the giant spring; imaging the sarcomeric muscle and the respiratory decline |
| R12 | ANO5 | CK + MRI fat fraction + MFM-32 | very high CK is the fingerprint; fat fraction the tracker; MFM-32 the function |
| D1–D3, D5 | DNAJB6/TNPO3/HNRNPDL/COL6 | contracture + respiratory readouts | the folding/traffic/ECM forms; the burden is stiffness and breathing, not just weakness |

## 4. The honest note

This map is a decision tool, not a test menu a patient should read alone. It
says which number answers which question; it does not say which number a
given person needs — that is a neuromuscular clinic's job, and the first move
is still the genetic diagnosis that names the subtype. What the map does is
make the measurement problem legible, so that a trial (or a clinician) stops
reaching for one universal biomarker and reaches for the readout the
mechanism actually demands. The measure follows the mechanism, exactly as the
fix does.
